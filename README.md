# Flask 

Flask is a lightweight and flexible Python web framework used to build web applications and REST APIs. It provides the essential tools to get started quickly while allowing developers to add extensions and features as their projects grow.

##  What is Flask?

Flask is a micro web framework written in Python. It is called a microframework because it provides the core functionality needed to build web applications without forcing developers to use a specific project structure or a large collection of built-in tools.

##  Key Features

- Lightweight and easy to learn
- URL routing and request handling
- Dynamic HTML templates using Jinja2
- Support for REST API development
- Flexible project structure
- Extension support for databases, authentication, and more
- Built-in development server and debugging tools
